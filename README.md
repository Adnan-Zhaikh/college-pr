## Why this repo exists

College practicals usually end up as scattered files on a laptop, and then they're lost. I wanted them in one place, in order, where I could revise before exams and see how my programming improved over the semester. There's no fixed roadmap here: each program is simply what we were taught at that point, so the folders grow as the course moves forward.

## How the repo is organized

- One folder per subject.
- Programs are kept in the same order as the practical list, so you can follow them from the first to the latest.
- The repo is updated after each practical is performed, and old programs are changed when I improve or fix them.

## What I learned

- **Data structures in Python:** how structures like these are built and how they behave, by writing them instead of only reading about them.
- **Operating system concepts:** writing the ideas behind an OS as Python programs makes them easier to understand than theory alone.
- **Java fundamentals:** classes, objects, and the core language features, building up from simple programs.
- **Maven:** using a build tool to manage a Java project and its dependencies.
- **SQL connectivity:** connecting a Java program to a database, then reading and writing data from code.
- **Advanced Java topics:** going beyond the basics once the fundamentals were solid.

## Running the programs

**Python (`DSA_PY`, `OS_practical`):** needs Python 3.

```bash
python filename.py
```

**Java (`JAVA_practical`):** needs a JDK.

```bash
javac FileName.java
java FileName
```

For the Maven programs, open the project folder and use:

```bash
mvn compile
mvn exec:java
```
